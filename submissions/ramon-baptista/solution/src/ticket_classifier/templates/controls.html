Controles e limites

Três barreiras fazem a IA parar antes que uma dúvida vire encaminhamento errado.

01

Pausa de emergência

{{ 'Ligada — automação interrompida' if kill_switch else 'Desligada — regras normais ativas' }}

Se surgir um problema, a operação envia todos os tickets para pessoas imediatamente. O risco evitado é manter uma automação com falha em funcionamento.

Controle técnico: TICKET_CLASSIFIER_KILL_SWITCH.

02

Barreira de idioma

{{ 'Ativa' if language_guard_ok else 'Indisponível' }}

Quando a barreira detecta idioma não validado, nenhuma fila é sugerida e uma pessoa assume. Ela reduz o risco, mas não é infalível: na validação, 14 de 812 textos em português não foram detectados (n=812 PT), por contagem exata de escapes.

03

Arquivos sob conferência

{{ 'Impressões digitais confirmadas' if integrity_ok else 'Arquivos diferentes do original' }}

O sistema confere a impressão digital do modelo e das proteções antes de começar. Se um arquivo mudou, a análise é bloqueada para não exibir um resultado sem prova.

O que esta versão ainda não promete

Ela separa oito assuntos internos aprendidos em inglês. O score não é uma probabilidade calibrada. A faixa mais segura ainda comete erros. E tickets em português brasileiro ainda não foram validados. Por isso, a ferramenta apenas encaminha quando suas regras permitem; ela não resolve o chamado nem substitui a supervisão da operação.
