Ver contas e origem dos números

Na linguagem da fila: VP = mandou certo ({{ row.VP|number_br }}); FP = mandou para esta fila por engano ({{ row.FP|number_br }}); FN = deixou escapar desta fila ({{ row.FN|number_br }}); VN = corretamente não mandou para esta fila ({{ row.VN|number_br }}).

Precisão = {{ row.VP|number_br }} ÷ ({{ row.VP|number_br }} + {{ row.FP|number_br }}) = {{ row.precision|decimal_br(4) }}
Recall = {{ row.VP|number_br }} ÷ ({{ row.VP|number_br }} + {{ row.FN|number_br }}) = {{ row.recall|decimal_br(4) }}
Especificidade = {{ row.VN|number_br }} ÷ ({{ row.VN|number_br }} + {{ row.FP|number_br }}) = {{ row.specificity|decimal_br(4) }}
F1 = 2 × precisão × recall ÷ (precisão + recall) = {{ row.f1|decimal_br(4) }}
